\# 🤖 Windows 11 AI Agent (RU)



Локальный AI-агент на CPU: понимает русский, помнит диалог, выбирает инструменты, ищет в базе знаний, работает в Telegram и CLI.



\## ✨ Возможности



\- 🧠 \*\*LLM\*\*: Qwen2.5-7B-Instruct-Q4\_K\_M (llama.cpp, CPU only)

\- 🔍 \*\*RAG\*\*: 552 документа, эмбеддер `BAAI/bge-m3` (1024d), порог 0.60

\- 🛠 \*\*Инструменты\*\*: математика, погода, курсы валют, Wikipedia, RAG

\- 💬 \*\*Память\*\*: SQLite, контекст 10 сообщений, мультиюзер

\- 🛡 \*\*Безопасность\*\*: защита от промпт-инъекций (`prompt\_guard.py`)

\- ⚡ \*\*Скорость\*\*: ответ 1–3 сек, загрузка модели 3–6 сек

\- 🤖 \*\*ReAct\*\*: цикл планирования + fallback на planner
